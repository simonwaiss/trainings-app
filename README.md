# Trainings-App

Simons Trainings-Log als Web-App: https://simonwaiss.github.io/trainings-app/

Auf dem iPhone in Safari öffnen, Teilen → „Zum Home-Bildschirm“. Funktioniert ohne Netz; Änderungen gehen an die
Datenbank, sobald wieder Netz da ist.

Entwickeln: `npm install`, `npm run dev`. Prüfen: `npm run pruefen`. Regeln für Agenten: `AGENTS.md`.
